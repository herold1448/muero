# 정문 인근 → 중앙도서관 화면 기록 분석

분석 대상: 사용자가 제공한 88.8초 화면 녹화(2026-11-23). 약 3초 간격으로 전체를 살피고 0, 6, 12, 18, 24, 30, 36, 42, 48, 54, 60, 66, 72, 78, 84, 87초 프레임을 재확인했다. 이 파일에는 네이버 로드뷰 영상이나 프레임을 넣지 않는다. **영상 속 장면은 촬영 날짜가 2026년 2월과 2025년 5월로 섞여 있어 연속 촬영된 현장 주행 기록이나 최신 현장 상태가 아니다.** 사진 속 폭·높이·각도는 실측할 수 없다.

## 시간대별 관찰

| 구간 / 핵심 프레임 | 영상에서 직접 확인 | OSM과 대조한 사실 | 미확인·추정 및 구현 범위 |
|---|---|---|---|
| 0–24초 / 3, 6, 15, 21, 24초 | 정문처럼 보이는 출입 시설, 나란히 선 가로수, 녹지 중앙분리대, 포장된 차로, 노면 방향표시, 붉은 바탕과 흰 줄의 횡단보도, 차와 보행자 | OSM `1120956407`에는 `민주대로`/`highway=pedestrian` 선형이 있다. 남쪽 끝은 `[126.9046448,35.1723634]`; 전남대 공식 안내도의 정문 코드는 E01. | 영상 시점과 E01의 정확한 좌표는 대응되지 않음. `pedestrian` 태그와 영상의 차도 장면을 동일 위치로 단정할 수 없음. 차선 폭, 횡단턱·가로수별 위치는 미상. |
| 30–48초 / 30, 33, 42, 45초 | 열주 형태의 밝은 외관 건물, 옆면이 붉은 벽돌처럼 보이는 건물, 포장 차로와 경계석, 나무·잔디, 복수의 횡단 지점, 붉은 포장 영역 | OSM에는 이 권역의 건물 외곽 및 `footway=sidewalk`·`footway=crossing` 선이 포함됨. | 건물 ID와 프레임의 1:1 대응, 실제 층수·입구, 도로·보행로 면형/폭은 미확인. 건물 ID를 임의로 지정하지 않음. |
| 54–72초 / 54, 60, 63, 66, 69, 72초 | 붉은 포장과 차로의 경계, 수목, 돌을 쌓은 화단 경계, 외벽이 붉은 건물, 흰색 건물의 외부 계단·손잡이, 다른 위치의 넓은 건물 전면 | OSM 건물은 실제 위경도 외곽을 제공. OSM `highway=steps`는 통행 제외할 수 있는 별도 유형. | 이 구간의 화면 표기 촬영월이 2025년 5월이다. 영상의 계단 위치를 OSM 계단 ID에 아직 대응하지 못했으므로 새 장애물 좌표를 만들지 않음. 경사로·단차·지형 고도 미측정. |
| 78–88초 / 78, 81, 84, 87초 | 굴착기, 콘·임시 펜스, 파인 노면, 단색의 높은 건물, 노란 횡단 표시, 차량 통행 | OSM 좌표만으로 장비의 현재 위치·작업 범위를 식별할 수 없음. | 화면 표기 촬영월은 2026년 2월. 2026년 11월 현재 공사 중이라는 근거가 없어 제보 데이터나 경로 차단에 반영하지 않음. 현장 제보 후 확인 필요. |

## 요소별 증거 구분

| 요소 | 영상 관찰 | 다른 원본과 대조 | 실측 전 적용 |
|---|---|---|---|
| 건물 | 붉은 외벽·밝은 열주·회색 띠형 외관 | OSM 원본 건물 폴리곤; 전남대 공식 지도 B02 도서관본관, E01 정문 표기 | B02 건물색은 도서관의 공식 홍도 명칭에 맞춘 시각화 표현. 창문·지붕은 생성 규칙 기반 추정이며 입면 측량이 아님. |
| 도로 | 포장·차선·중앙분리대 확인 | 보유 OSM에는 이 시범 차도의 신뢰 가능한 면형/도로 중심선 없음 | 도로 차선·실제 폭을 새 지리객체로 만들지 않음. |
| 인도 | 차도 옆 보도블록·붉은 포장 확인 | OSM `sidewalk`/`footway` 중심선 | 화면의 너비·높이 차이는 추정. 표면 폭 표시에도 미확인 문구 유지. |
| 횡단보도 | 흰 줄과 붉은 바탕 확인 | OSM `footway=crossing` | OSM 선에 줄무늬를 그리되 실측 턱/정확한 경계는 미확인. |
| 경사로·계단 | 건물 외부 계단·손잡이 일부 확인 | OSM `steps` 구간 별도 분류 | 램프의 기울기·연결 고도는 확인할 수 없으므로 실물 경사면으로 생성하지 않음. |
| 조경 | 가로수, 화단, 잔디 확인 | 제공 JSON에는 개별 수목 위치·면형 없음 | 나무의 좌표를 임의로 확정하지 않음. |
| 장애물 | 굴착기와 콘 확인 | 최신 제보 또는 현장 확인 기록과 연결 안 됨 | 날짜가 다른 영상의 장비를 현재 차단 데이터로 저장하지 않음. |

정문 시범 경로에서는 태그 충돌 가능성이 있는 OSM way `1120956407`을 원본에서 삭제하지 않고 **경로 계산에서만 임시 제외**한다. 이 경우의 후보 경로는 약 821m이며 보도 344m·횡단 62m·상세 미확인 보행로 415m로 이뤄진다. 전 구간은 현장 검증 전으로 안전 경로가 아니다. 사용자가 다른 출발지를 선택하면 v7의 기존 경로 그래프 정책을 그대로 사용한다.
