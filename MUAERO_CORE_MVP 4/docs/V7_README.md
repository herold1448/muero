# GILON 3D v7 — 전남대학교 휠체어 접근성 경로 **검증 전 실험판**

> 현장 검증을 마치지 않은 OSM 기반 연구용 MVP입니다. 현재 앱에서 계산한 경로를 실제 휠체어 이동의 안전 경로로 사용하지 마세요. 완성된 실시간 GPS 내비게이션이 아닙니다.

## 빠른 실행 (Mac)

1. v7 ZIP을 압축 해제합니다. 기존 v6는 그대로 보관하세요.
2. Terminal에서 `cd ` (cd 뒤에 공백) 입력 후 새 `GILON_JNU_v7` 폴더를 드래그하고 Enter를 누릅니다.
3. `python3 server.py` 를 실행합니다.
4. Chrome 주소창에 `http://localhost:4173/?v=70`을 엽니다.
5. 최초 실행 때 동봉된 OSM JSON이 자동으로 로드됩니다. 오른쪽 상단 `OSM 좌표 기반` 표시를 확인하세요.
6. 기본 출발지 `경영대 2호관`, 도착지 `중앙도서관`에서 `경로 계산하기`를 선택합니다.
7. 이 경로는 **건물 출입구가 아닌 인근 OSM 보행로 접점** 사이의 탐색용 경로입니다. `▶ 시연`은 **실제 GPS 주행이 아닌 가상의 휠체어 이동**입니다.

기존 서버가 켜져 있으면 Ctrl+C로 종료한 뒤 실행합니다. Python 표준 라이브러리만 사용하므로 Python 의존성 설치는 필요 없습니다. 브라우저에서 WebGL 지원이 필요합니다.

## 동봉된 공개 데이터

- `data/campus_paths.json`: 사용자 제공 Overpass OSM 원본. way 928개
- `data/campus_buildings.json`: 사용자 제공 Overpass OSM 원본. 건물 외곽 way 1,422개
- 캠퍼스 내부뿐 아니라 주변 지역도 포함됩니다. 전체 캠퍼스 경계가 정밀하게 마스킹된 자료가 아닙니다.
- 분류: 인도 364 / 횡단 보행 구간 155 / 보행자 전용 8 / 기타 보행로 353 / 계단 36 / 혼용도로 12
- **일반 자동차 도로 전체 데이터는 아직 없습니다.** 시각화에서 보이지 않는 차도를 있다고 추정하거나, 누락된 인도를 자동 생성하지 않습니다.
- 길 폭, 턱 높이, 정량 경사 자료는 제공 데이터에서 대부분 확보하지 못했습니다. 전체 노선 현장 검증은 0건입니다.
- 출처: © OpenStreetMap contributors, ODbL 1.0. 원본 `data/`에 OSM 저작권/시각정보가 포함돼 있습니다.
- 네이버 위성·거리뷰 사진은 포함하거나 스크래핑하지 않았습니다.

## v6에서 변경된 점

1. 건물 중심을 보행로로 바로 연결하던 방식을 수정. 건물 외곽 근처 보행로 접점(접근 후보)으로만 탐색합니다. 실제 출입구 확인 전에는 도착 완료를 의미하지 않습니다.
2. 일반 지도 클릭 또는 GPS 위치가 보행로로부터 너무 멀면 자동 연결하지 않으며 경로가 없다고 알려줍니다(스냅 거리 기본 18m).
3. 총 경로 길이와 **미검증 경로 거리(m)**를 분리 표시합니다.
4. 경로 3D 색상: 앰버=접근성 미검증, 민트=관리자 현장 확인 기록. 어느 색도 독립 안전 검증의 의미는 아닙니다.
5. 인도/횡단/계단/혼용/차도 분류 유지, 확인된 계단·일반 차도는 기본 탐색 제외.
6. 횡단보도를 현장 조사 완료로 취급하려면 양쪽 연석 상태 기록이 필요합니다.
7. 사용자 설정 최소 길 폭(0.9/1.0/1.2/1.4m) 및 경사 제한을 수집합니다. 설정값은 **사용자 자체 기준**이며 권고 안전기준으로 해석해서는 안 됩니다.
8. 출입구 현장 조사 관리 화면. 이름·위경도·접근성·조사일·현장 메모를 로컬에 저장합니다. 건물 중심은 실제 출입구로 사용하지 않습니다.
9. 관리자 구간 수정의 이력 확인 및 마지막 수정 되돌리기.
10. 모바일 패널 및 보행 신뢰도 경고 표시 개선.
11. 기존 사용자 입력/데모/OSM 가져오기/장애물 신고/3인칭 시연/3D 건물/지도 클릭 등을 유지합니다.

**엔진 설명:** 기존 v6의 렌더러는 `src/renderer.js`의 *자체 WebGL* 구현입니다. Three.js 기반이라고 말할 수 없으므로 이번에는 실제 코드를 유지해 개선했습니다. 차후 Three.js 전환은 별도 작업입니다.

## 조사·관리 사용법

### 관리자: 보행로
1. 오른쪽 상단 `구간 관리` → `⌖ 지도에서 구간 선택` 또는 `OSM way ID` 검색.
2. 기본은 **선택한 선분만** 수정합니다. 동일 Way 전체 변경은 편집 범위를 바꿀 때만 적용.
3. 인도·차도·횡단 유형, 통행 차단, 길 폭, 경사, 노면, 턱 상태, 횡단 양측 턱, 확인 메모를 기록합니다.
4. 조사 기록이 존재한다는 것과 독립적인 안전 검증이 완료됐다는 것은 다릅니다.
5. `변경 이력`에서 기록을 확인하고 `마지막 구간 변경 되돌리기`를 사용할 수 있습니다.

### 관리자: 건물 출입구
1. 오른쪽 상단 `출입구` → 목적지 건물 선택 또는 건물명 입력.
2. 지도에서 좌표 선택(또는 직접 위경도 입력). **실제 위치를 현장에서 확인**해야 합니다.
3. `접근성 상태`, `조사 상태`, `조사 날짜`, `현장 메모`를 입력합니다.
4. 기록이 남아도 **해당 출입구와 보행로 간 연결은 미확인**이므로 UI에 연결 거리 확인 필요를 표시합니다.
5. 불확실하면 `미확인`으로 저장합니다.

### 현장 조사 체크리스트
`surveys/first-route-field-checklist.csv`는 실제 OSM 경영대 2호관 → 중앙도서관 주변 보행 후보 18개 구간의 OSM ID, 좌표, 구간 길이가 채워진 현장 조사표입니다. **측정 전 항목은 빈칸**입니다. CSV는 Excel이나 Google Sheets에서 열 수 있습니다.

### 누락된 차도 데이터
데이터 관리 화면 `차도 조회 쿼리 복사` → Overpass Turbo에서 `실행` → `내보내기` → `원본 OSM 데이터` 다운로드 → 앱 `차도·혼용도로 JSON 추가`. 외부 서버가 느리거나 인터넷이 차단되면 다운로드에 실패할 수 있습니다. 이미 동봉된 보행로/건물 데이터는 계속 사용됩니다.

## 서버 정보 / 보안

- `server.py`는 **127.0.0.1(loopback)에서만** 실행됩니다. 같은 Mac의 Chrome에서 접속 가능합니다.
- 관리자 인증이 없는 **단일 기기 연구용 로컬 앱**입니다. 인터넷에 그대로 공개하거나 다른 사용자와 공유하는 운영 서버로 사용해서는 안 됩니다.
- `data/reviews.json`, `data/entrances.json`, `data/reports.json`은 사용자가 직접 저장할 때 생성됩니다.
- 이력 `data/history.json`은 변경 내용(사진 내용은 별도 축약)으로 기록됩니다.
- 원본 OSM JSON을 덮어쓰지 않고 관리자의 수정 레이어를 별도 JSON으로 보관합니다. 단, `/api/import/*`는 동봉한 원본 JSON 파일을 교체할 수 있으므로 업로드 전 백업을 권장합니다.
- 휴대폰의 **실제 GPS 주행과 경로를 따라 실시간 안내하는 기능은 구현되지 않았습니다.** Mac의 웹앱은 현재 위치를 한 번 조회해 출발지로 설정하는 기능까지만 제공합니다. 스마트폰에서 실사용하려면 HTTPS·인증·기기별 테스트·GPS 매칭·현장 검증이 필요합니다.

## 자동 검사

Node.js가 있으면 프로젝트 폴더에서:

```bash
for file in tests/*.mjs; do node "$file"; done
python3 tests/server_v7.py
```

`tests/browser_v7.py`는 Chromium+Playwright로 자동 UI 테스트를 시도하는 선택적 스크립트입니다. 이 모델 실행환경에서는 Chromium이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 **성공하지 않았습니다**. 로컬 Mac의 브라우저에서 수동 검증해야 합니다. 자세한 기록은 `TEST_RESULTS.md`를 참조하세요.

## 남은 핵심 과제

- 전남대 **실제** 인도/차도 완전한 분리: 아직 별도 차도 JSON과 현장 조사 필요
- 건물 현장 확인 출입구와 보행로의 실제 연결 증거 수집
- 횡단보도 양측 턱·경사율·폭·노면 실측
- 누락 보행로 수동 추가·연결 편집용 지도 제작 도구
- 검증 방식과 측정 주기 정의, 휠체어 이용자 동행 조사
- 실제 휴대폰 HTTPS 환경과 GPS 위치 추적/맵매칭/재탐색
- 멀티유저 관리자 인증, 민감 사진 및 개인정보 접근통제
- 고급 3D 지형/현실적 외관 및 거리 사진 재사용 권한 확인
