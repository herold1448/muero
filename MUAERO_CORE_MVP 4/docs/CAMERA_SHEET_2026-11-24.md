# 주행 카메라·하단 패널 수정 보고 — 2026-11-24

## 제공된 실행 화면 분석

사용자가 제공한 20.75초 Mac 화면 녹화에는 중앙도서관 후보 경로를 따라가는 동안 건물 벽과 반복 창문이 화면 대부분을 차지하고, 휠체어가 확인되지 않는 장면이 반복된다. 제공된 조감도 스크린샷은 건물의 전체 형태가 단순하게 보이는 상태를 보여준다. 녹화 속 428m, GPS 오차 ±35m는 그 실행 시점의 값이다.

소스 원인은 `src/renderer.js`의 기존 주행 카메라가 매 프레임 휠체어에서 진행 방향 반대로 9m, 위로 5.8m에 놓이면서 건물 외곽과 눈높이 차폐를 전혀 검사하지 않은 점이다. 큰 하단 패널은 같은 캔버스 위에 항상 펼쳐져 있었다. 녹화만으로 GPU 기하 오류나 실측 건물 위치 오류를 확정하지 않았다.

## 구현

- `src/camera.js`: 기존 OSM 외곽과 높이 태그 또는 추정 높이로 카메라의 건물 내부 진입 및 휠체어까지의 차폐를 검사한다. 뒤쪽 시점을 먼저 찾고, 차폐가 있으면 거리·측면·높이를 조정한다. 경로 자체가 건물 내부를 지난다면 시야 확보 불가 상태를 알린다. OSM 모델이 실제 건물 위치와 완전히 일치한다고 주장하지 않는다.
- `src/renderer.js`: 추적 방향의 완만한 회전, 충돌 시 부드러운 보간 위치의 재검사, 시점 초기화, 패널 높이만큼의 카메라 투영 보정. 경로 좌표·A* 코드는 변경하지 않았다. 휠체어 모델은 기존 메시와 실제 경로 보간을 유지한다.
- `index.html`, `mvp.css`, `src/mvp.js`: 3D 따라가기를 시작할 때 검색창을 감추고 패널을 자동으로 접는다. 접힌 화면에 목적지, 남은 거리, 미검증 상태와 펼치기 버튼을 표시한다. 펼친 화면에는 기존 출발지·상세 위험·일시정지·종료·제보가 남는다. 반복 접기·펼치기에서 경로 진행 변수를 초기화하지 않는다. 키보드 버튼 및 `aria-expanded`, 모바일 안전 영역과 모션 감소 설정을 반영했다.
- `tests/browser_mvp.cjs`: 1440×900, 390×844, 375×667에 대해 접기·펼치기·시점 복구와 제보 창을 검사하고, 실행 가능할 때 주행 스크린샷을 남기도록 확장했다.

기존 OSM 파일, 관리자 기록 및 사진 제보 저장 파일은 변경하지 않았다. 별도의 실제 DEM과 차도/회전교차로 면형은 여전히 없다. 이 빌드의 3D 카메라 시야 개선은 기하 검사 범위에서만 확인됐으며 현장 검증 경로를 뜻하지 않는다.

## DEM 확보 경로와 필요한 검증

[공공데이터포털의 국토지리정보원 DEM 파일](https://www.data.go.kr/data/15059920/fileData.do)은 IMG 형식·무료로 안내한다. 국토정보플랫폼의 [공공데이터 이용정책](https://map.ngii.go.kr/nw/common/login/publicInformation.do)은 공공데이터 활용 범위와 제3자 권리 예외를 안내한다. 그러나 **이 실행 환경에서는 실제 용봉캠퍼스 격자 원본을 다운로드하지 못했다.** 공개 자료의 실제 셀 크기, 제작일, 수직 기준면, 용봉캠퍼스 범위 포함 여부는 파일마다 확인해야 한다.

사용자 또는 자료 담당자가 국토정보플랫폼의 국토정보맵에서 `전남대학교 용봉캠퍼스` 또는 `광주 북구 용봉동`을 검색해 **수치표고모델/공개 DEM** IMG와 메타데이터를 내려받은 뒤, 사용 허가와 해상도를 확인한다. 현재 앱 전체 범위(`35.167–35.184°N`, `126.896–126.919°E`)를 덮는 원본 또는 합법적으로 모자이크한 GeoTIFF/IMG가 필요하다. `python3 -m pip install rasterio pyproj` 후 아래처럼 전처리한다.

```bash
python3 scripts/import_dem.py /path/to/authorized_dem.img \
  --vertical-datum '원본 메타데이터에 명시된 기준면' \
  --license '해당 파일의 실제 이용 조건' \
  --source '제공기관·자료명·제작연도'
```

생성된 `data/terrain/grid.json`의 좌표·NoData·단위·기준면을 검사하고 현장 고도 기준점과 비교해야 실제 지형 적용으로 판단할 수 있다. 90m급 등 낮은 해상도의 DEM만 확보된다면 보행로의 작은 경사, 연석 및 램프를 측정한 것으로 취급하지 않는다.

차량 도로는 현재 첨부 OSM 경로 파일에 없다. 공개 OSM 원본을 별도로 합법적으로 내려받으면 `data/campus_roads.json`으로 두어 **시각화 전용**으로 읽을 수 있다. 도로 중심선으로 확장한 폭은 추정값이다. 회전교차로 중앙 교통섬의 실제 폴리곤·진출입로 및 현장 확인 정보 없이는 정확한 회전교차로 모델을 만들 수 없다.
