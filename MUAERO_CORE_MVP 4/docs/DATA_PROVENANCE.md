## 수치의 증거 수준

- 좌표: EPSG:4326 `[경도,위도]`. Three.js에서는 기존 `toXY()`가 원점 `35.1765,126.9078`을 기준으로 m 단위 x(동쪽), z(남쪽)를 만든다. 원래 WGS84 좌표를 파일에서 유지한다.
- 정문 **후보점**: `[126.9046448,35.1723634]`은 OSM 민주대로 way `1120956407`의 남쪽 끝이다. E01 표지/출입구를 GPS로 측량한 점이 아니며 전남대 정문이라는 대응도 확인 중이다.
- 건물: OSM `height`가 있더라도 실제 실측을 뜻하지 않는다. 렌더러는 유효한 태그 높이, 층수×3.3m, 기본 10m 순서로 시각화하며 OSM 태그와 모든 추정치를 현장 측정값으로 간주하지 않는다. 평지 y=0은 미확보 DEM을 대신하는 시각화용 평면이다.
- 보행로: OSM 중심선은 실제 양쪽 경계/폭이 아니다. 미측정 폭은 화면에서 사용하는 예시 폭일 뿐이며 횡단보도, 턱·경사·단차·노면은 직접 조사해야 한다.
- 분류 충돌: 영상 차로와 OSM `민주대로`(pedestrian)가 같은 시설인지 불명확하다. 시범 기본 탐색에서는 그 way만 제외한다. OSM 원본과 일반 경로 계산 정책은 유지한다.
- 영상의 공사 장비는 2026년 2월 장면이며 2026년 11월의 통행 차단 근거가 아니다. 관리자 제보에 자동 등록하지 않았다.

## 현장·기관 자료 확보 순서

1. 정문 E01의 실제 휠체어 진입점과 도서관 B02 출입구를 대학 시설관리부서/장애학생지원 부서에 확인하고 좌표·촬영일을 기록한다.
2. 시범 후보의 보도·차도 경계, 횡단 턱 cm, 통행 폭 m, 포장, 유효 경사율 %, 경사 시작/끝 표고 및 2026년 11월 공사 상태를 현장에서 조사한다.
3. NGII 해당 DEM·수치지도 도엽과 메타데이터를 허용된 수단으로 확보하고 수직 기준을 확인한 다음, 보행로 높이와 별도 원본으로 합친다.
4. 대학이 재사용을 허가한 도면 또는 자체 촬영 사진으로 도서관 및 주변 주요 건물의 지붕/창/전면부와 실제 외벽 색을 검증한다.
