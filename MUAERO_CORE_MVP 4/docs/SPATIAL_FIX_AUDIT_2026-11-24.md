## 필요한 자료와 적용

1. **DEM:** 국토지리정보원 등 합법적 원본 GeoTIFF/IMG, 제작일·수평 CRS·수직 기준면·셀 크기·이용 조건. `scripts/import_dem.py`로 `data/terrain/grid.json` 생성 후 현장 기준점과 비교.
2. **차도·회전교차로:** 해당 범위 OSM 차량도로 원본 JSON을 `data/campus_roads.json`으로 별도 저장 가능. 이 경우에도 중심선 폭은 추정이며 중앙섬은 실제 Polygon/면형, 출입로 방향과 공간 연결 자료가 추가로 필요.
3. **인도·횡단:** 실제 폴리곤 경계/최소 폭·연석 높이·단차, 횡단 양쪽 연결, 공사 날짜별 통행 상태. 현장 측량/검증 기록이 필요.
4. **건물:** 공식 캠퍼스 경계와 건물 코드–OSM ID 대응표, 층별·지붕·출입구 도면이나 이용 허가된 사진. 저작권이 불명확한 영상 프레임을 텍스처로 쓰지 않음.
