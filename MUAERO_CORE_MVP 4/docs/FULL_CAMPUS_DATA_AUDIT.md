# 용봉캠퍼스 전체 자료·구현 검증 — 2026-11-23

## 범위와 사실

이번 버전은 기존 정문–도서관 시범판을 복사해 보유 OSM 스냅샷 전체를 정규화하고, 실제 DEM을 받을 수 있는 지형 경로를 구현했다. **공식 용봉캠퍼스 경계, 원본 DEM, 차도 면형은 아직 확보하지 못했다.** 전체 용봉캠퍼스 디지털 트윈 완성이나 모든 교내 건물 전수 확인을 주장하지 않는다. 평면 배경은 데이터 부재를 뜻한다.

수치와 원본 해시는 `exports/full_campus_qa.json`, 90건 이름 대조는 `exports/official_name_audit.json`에 있다. 자료는 WGS84 GeoJSON으로 `exports/full_campus_buildings.geojson` 및 `exports/full_campus_paths.geojson`에 저장했다. OSM node/way 원본과 v7의 관리자 데이터는 수정하지 않았다. 정문 시범 영역의 `data/gate_library_*.geojson`도 보존했다.

## 공식 대조와 누락 가능성

- 공식 캠퍼스 안내: https://mba.jnu.ac.kr/mba_eng/20496/subview.do (A01–D20 건물 90개, E01 정문 등 기타 시설 표기). 텍스트 명칭·코드만 대조했으며 공식 이미지·도면은 재배포하지 않는다.
- 공식 시설 부지현황: https://sisul.jnu.ac.kr/sisul/13409/subview.do (용봉캠퍼스 도시계획 시설결정 면적 989,860㎡). 면적 표만으로 정확한 GIS 경계 선을 복원할 수 없다.
- 공식 B02 `도서관본관`과 현재 OSM `중앙도서관`, 공식 B04/B05 `경영대학 1/2호관`과 OSM 건물 이름 부재는 수작업 위치 대조 대상으로 등록했다. 이름 미일치는 OSM 외곽선 누락의 증거가 아니다.
- `docs/full-campus-osm-qa.png`는 OSM 좌표만 그린 **정적 QA 이미지**다. 캠퍼스 경계선이나 실제 브라우저 화면이 아니다. 주변 주택이 포함된 점을 쉽게 확인할 수 있다.

## 구현 구조와 제한

- `scripts/build_full_campus.py`: 원본 불변, 1,422개 외곽·928개 길 내보내기 및 이름 대조. 기존 파일에는 relation이나 MultiPolygon 요소가 없어서 그 유형은 **미검증**이다.
- `scripts/import_dem.py`: 별도로 적법하게 확보한 DEM의 CRS와 NoData, 전체 앱 영역 커버리지 확인 후 WGS84 위치·원본 해시·수직 기준면을 포함한 격자 생성. 입력 원본은 지정한 위치에 따로 보존한다. 미확보 상태에서는 실행하지 않았다.
- `src/terrain.js`, `src/renderer.js`: 유효한 `data/terrain/grid.json`이 있을 때만 원본 높이에 대해 1배 수직 배율의 지형 mesh/고도 조회를 사용한다. 길·건물 바닥·휠체어 시연 위치가 같은 `toXY()` 좌표 변환과 고도 조회를 쓴다. 지형 밖은 미측정이며 안전 경로로 간주하지 않는다.
- 렌더링 차도, 횡단, 계단, 보행 표면의 메시를 분리했다. 현재 원본에는 자동차 차도 자료가 없으므로 차도 면형/회전교차로 실제 구현으로 주장하지 않는다. 표면 폭과 바닥 간격은 시각화 값이다.
- 출입구·경사로·횡단보도 위치 및 이용 가능 여부는 DEM만으로 알 수 없다. 원본 v7 접근성·관리자·장애물 판정 로직을 유지한다.

## 검증 상태

자동 계산: `python3 scripts/build_full_campus.py`, `node tests/full-campus-v8.mjs`, 기존 JS/v7 서버 테스트. 수량·ID·좌표 왕복·고도 그리드 결측 차단/보간 검사는 통과했다. 지형 테스트의 입력은 **합성 격자**이므로 실제 고도 정확도의 증거가 아니다. 실제 DEM 입력, GIS 경계 판정, 건물 입면, 차도, 전체 캠퍼스 GPU 프레임버퍼, Mac Chrome, 모바일 브라우저는 미검증이다. 브라우저 실행 제한 및 이전 시범판의 결과는 `TEST_RESULTS.md`에도 기록했다.
